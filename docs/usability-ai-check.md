# AI 모의 사용성 점검 (2026-11-25)

> **실제 사용자 시험이 아니다.** AI(Claude)가 사용자 유형 5가지를 정하고, 실제 사이트(https://daily-english-eight-mocha.vercel.app, 로그인 없는 모드, 휴대폰 크기)에서 과제를 직접 눌러 보며 막히는 곳을 찾았다. 실제 사용자 수치나 의견으로 쓰지 않는다. 실제 베타 시험에서 같은 문제가 나오는지 다시 확인한다.

## 방법

- 도구: Playwright로 화면을 누르고 찍음, axe-core로 자동 접근성 검사(WCAG 2.1 A·AA)
- 범위: 로그인 없는 모드. 친구 기능, AI 교정, 서버 동기화, 안드로이드 앱은 이번 점검에 들어가지 않았다.

| 유형 | 과제 | 결과 |
| --- | --- | --- |
| P1 처음 온 영어 초보 | 첫 화면 → 로그인 없이 시작 → 안내 → 단어 하나 저장 → 복습 | 성공 |
| P2 친구가 보낸 슬랭을 찾는 사람 | "lowkey"가 무슨 뜻인지 앱에서 찾아 담기 | **실패**(찾을 방법이 없음) |
| P3 일기 쓰는 사람 | 기분 고르기 → 일기 쓰기 → AI 교정 → 저장 → 달력 | 저장·달력 성공, AI 교정은 로그인 필요 |
| P4 문법이 헷갈리는 사람 | 문법 꾸러미에서 담기 → 번역 연습 | 성공 |
| P5 좁은 화면·어두운 모드·보조 기술 | 320px 폭 11개 화면, 어두운 모드, 터치 영역, axe 검사 | 거의 통과(작은 링크 1개) |

## 잘 된 점

- 화면 오류(자바스크립트 오류) 0건
- 320px 폭에서 11개 화면 모두 가로로 넘치지 않음
- axe 자동 접근성 검사: 밝은 모드 11개 화면과 어두운 모드 홈에서 위반 0건
- 첫 화면에서 "로그인 없이 먼저 써 보기"가 화면 위쪽(스크롤 없이 보이는 곳)에 있음
- 단어 저장 → 퀴즈, 일기 저장 → 달력, 문법 담기 → 연습이 막힘 없이 이어짐

## 고칠 점 (중요한 순서)

| 순위 | 문제 | 누가 겪나 | 제안 |
| --- | --- | --- | --- |
| 1 | **꾸러미에 검색이 없다.** 친구가 보낸 `lowkey`의 뜻을 찾으려면 22개 묶음, 655개 표현을 하나씩 눌러 봐야 한다. 앱의 핵심 상황(친구 메시지의 모르는 말)에서 바로 막힌다. | P2 | 꾸러미 위에 검색칸(표현·단어·문법 전체). 단어장에서 낱말을 쓰면 꾸러미 뜻을 채워 주는 기능을 표현까지 넓히기 |
| 2 | **처음 온 사람은 AI 교정을 볼 수 없다.** 로그인 없는 모드에서는 "로그인하면 쓸 수 있어요" 한 줄뿐이라, 앱의 가장 강한 기능을 모르고 지나간다. | P1, P3 | 일기 화면에 "예시 교정 보기"(미리 만든 교정 결과)를 두어 로그인 전에도 결과 모양을 보여 주기 |
| 3 | **새 사용자의 홈이 0으로 가득하다.** "0일째 이어 쓰는 중", 흐린 "다시 보러 가기" 버튼, 이번 주 돌아보기 0·0·0·0. 첫날부터 비어 보인다. | P1 | 기록이 없을 때는 0 카드 대신 "첫 할 일 하나"(단어 하나 담기 / 오늘의 표현 담기)만 크게 |
| 4 | **퀴즈 방식 고르기가 복잡하다.** 퀴즈를 열면 방식 6가지와 "퀴즈 닫기"가 한 덩어리로 먼저 보인다. | P1 | "오늘 다시 보기"로 바로 시작하고, 나머지 방식은 "방식 바꾸기" 안으로 |
| 5 | **안내 마지막 단계가 일기 쓰기를 꼭 해야 하는 것처럼 보인다.** 큰 버튼이 "첫 일기 저장하고 시작하기"이고, 건너뛰기는 작은 글자다. | P1 | 건너뛰기를 버튼으로 키우거나, 마지막 단계 버튼을 "시작하기"로 하고 일기는 선택으로 |
| 6 | 꾸러미 뜻 채우기는 꾸러미에 있는 600개 단어에만 뜬다(`awkward`처럼 흔한 말도 없으면 직접 적어야 함). | P1 | 기대대로 동작함. 1번 검색과 함께 꾸러미 범위를 알려 주는 안내 정도 |
| 7 | 꾸러미 카드의 출처 링크(Tatoeba)가 48×15px로 작다. | P5 | 링크 줄 높이를 24px 이상으로 |

- 1~3번은 실제 베타 테스터에게도 같은 과제를 주고 같은 곳에서 막히는지 본다
