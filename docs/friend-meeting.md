# 친구와 함께 확인할 자료 (2026-11-23)

오늘 친구와 앱을 같이 보면서 확인하고 정할 것을 한 장에 모았습니다. 자세한 근거는 맨 아래 "자료 위치" 표의 문서에 있습니다.

## 1. 오늘 보여 줄 것 (15분 순서)

| 순서 | 보여 줄 것 | 어디서 | 말할 것 |
| --- | --- | --- | --- |
| 1 | 웹 앱 | `http://localhost:5173` (내 컴퓨터에서 켠 개발판, 실제 Supabase 연결) | 친구 원본의 노트 화면 틀 그대로, 위에 얹은 것들 |
| 2 | 홈 → 단어 저장 → 퀴즈 | 같은 화면 | 복습 6가지 방식: 카드 뒤집기, 뜻 → 표현, 객관식, 빈칸, 듣고 쓰기, 오늘 다시 보기 |
| 3 | 홈의 "헷갈리는 말" | 같은 화면 | 틀린 횟수를 쌓아 자주 틀리는 말만 모아 다시 풀기 |
| 4 | 연인과 한 문장 | 계정 두 개 필요(미리 준비) | 초대 번호, 하루 한 문장, 글자 반응 |
| 5 | 설정과 프로필 | 상단 톱니바퀴와 이름 동그라미 | 알림, 학습 언어, 데이터 내려받기, 계정 |
| 6 | 안드로이드 앱 | 에뮬레이터 | 웹과 같은 화면과 기능 |
| 7 | 코드와 기록 | `https://github.com/ggpus111/daily_english` | 33개 커밋, 테스트, 문서 |

## 2. 친구 원본에서 달라진 것

| 영역 | 친구 원본 | 지금 |
| --- | --- | --- |
| 플랫폼 | 웹 | 웹(PWA) + 안드로이드 앱, 코드 하나 |
| 학습 언어 | 영어 | 영어, 일본어, 중국어, 스페인어, 프랑스어, 한국어(외국인이 한국어를 배울 때) |
| 복습 | 영어 → 뜻, 뜻 → 영어 | 간격 반복, 객관식, 빈칸, 듣고 쓰기, 헷갈리는 말 모아 보기 |
| 첫날 콘텐츠 | 없음 | 연인·친구 대화 표현과 단어 꾸러미(언어별) |
| 일기 | 직접 번역 | AI 교정(앱 안, 동의 후 사용, 하루 한도) |
| 연인 | 없음 | 하루 한 문장 주고받기, 반응, 새 문장 알림 |
| 설정·프로필 | 언어, 로그아웃 | 알림, 학습, 데이터 내려받기와 가져오기, 이름과 계정, 비밀번호 |
| 로그인·보안 | 이메일 | 이메일 + 구글 + 카카오, 행 단위 보안, 보안 헤더, 초대 번호 무작위 대입 차단 |
| 테스트 | 없음 | 단위 140개, 브라우저 129번(데스크톱+모바일, 접근성 검사 포함), 안드로이드 실기 8개 |

**그대로 둔 것**: 콘셉트 문장, 기록 4가지, 홈의 노트 디자인 틀(영문 라벨, 번호 카드, 한마디 패널 포함). 한때 장식을 걷어 봤다가 이전 모습이 더 낫다고 판단해 되돌렸습니다.

## 3. 친구와 정할 것

1. **저장소 공개와 크레딧**: GitHub 저장소가 지금 **공개**입니다. 친구가 만든 원본 코드를 이어받은 것이라, 공개해도 되는지와 README에 친구 이름·기여를 어떻게 적을지 친구에게 확인해야 합니다. 동의가 없으면 비공개로 바꿉니다(Settings > General 맨 아래).
2. **원본 요소 유지**: 노트 틀, 번호 카드 등 친구 기획 요소를 어디까지 유지할지.
3. **이 앱을 어떤 사람에게 보일지**: 지금 대상은 "외국인 연인·친구와 대화하는 사람"입니다. 친구가 생각한 대상과 맞는지.
4. **베타 테스트**: 친구가 아는 사람 5~10명에게 써 보게 할 수 있는지(발표·이력서에 실제 사용 수치가 필요합니다).
5. **5개 언어 검수**: 일본어, 중국어, 스페인어, 프랑스어, 한국어 뜻과 예문은 원어민 검수를 받지 않았습니다. 아는 사람이 있는지.
6. **앱 이름과 아이콘**: 현재 Daily English와 "d." 로고를 계속 쓸지.

## 4. 친구가 직접 써 보며 볼 것

- [ ] 가입하고 로그인한다(이메일)
- [ ] 단어를 저장하고 새로고침해도 남는다
- [ ] 퀴즈 모드를 하나씩 눌러 본다(음성 읽기가 되는 기기에서는 듣고 쓰기도)
- [ ] 일부러 틀려 보고 홈에 "헷갈리는 말"이 생기는지 본다
- [ ] 설정에서 알림 스위치와 학습 언어를 바꿔 본다
- [ ] 연인 기능: 계정 두 개로 초대 번호, 문장, 반응을 주고받는다
- [ ] 막히거나 어색한 곳을 적는다(문구, 버튼 위치, 색)

## 5. 지금 상태 (되는 것과 안 된 것)

**되는 것 (자동 테스트와 실제 확인)**
- 위 기능 전체가 자동 테스트를 통과합니다(가짜 서버 사용).
- 실제 Supabase 프로젝트에 표를 만들었고, 모든 표에 행 단위 보안이 켜져 있습니다. 로그인 없이 읽으면 빈 결과가 나오고, 초대 함수는 거부됩니다.

**아직 안 된 것 (숨기지 않고 말하기)**
- 실제 서버로 한 가입, 로그인, 연인 두 계정 점검은 오늘 처음 해 보는 단계입니다.
- 서버 함수(AI 교정, 웹 알림)는 아직 배포 전입니다.
- 앱을 닫은 안드로이드의 서버 푸시(FCM)는 없습니다. 앱을 열면 알려 줍니다.
- 5개 언어 콘텐츠는 원어민 검수 전입니다.
- 실제 사용자는 아직 없습니다. 지금 문서의 숫자는 외부 데이터(리뷰, 말뭉치) 분석입니다.
