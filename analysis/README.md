# 경쟁 앱 사용자 리뷰 분석

Daily English의 기능과 디자인 방향을 정하려고, 비슷한 앱 11개의 앱스토어 리뷰 5,142건을 분석했습니다.

## 질문

1. 언어 학습, 단어장, 대화, 일기 앱 사용자는 무엇 때문에 낮은 별점을 주고, 무엇 때문에 높은 별점을 주는가?
2. 그중 Daily English가 먼저 만들어야 할 기능과 피해야 할 것은 무엇인가?

## 데이터

| 항목 | 내용 |
| --- | --- |
| 출처 | Apple iTunes Search API(앱 정보), App Store 고객 리뷰 RSS(리뷰). 모두 공개 API |
| 나라 | 한국 App Store |
| 수집일 | 2026-11-12 |
| 규모 | 11개 앱, 리뷰 5,142건 (앱마다 최근 최대 500건, AnkiMobile은 142건) |
| 개인정보 | 작성자 이름은 수집하지 않음. 원본 리뷰는 저장소에 올리지 않고 집계 결과만 둠 |

| 묶음 | 앱 | 고른 이유 |
| --- | --- | --- |
| 학습 앱 | 듀오링고, 스픽, 말해보카, 케이크 | 퀴즈와 꾸준한 학습 |
| 단어장 | Quizlet, VoCat, AnkiMobile | 직접 만드는 단어장과 복습 |
| 실제 대화 | 헬로톡, 탄뎀 | 실제 사람과 나누는 대화 |
| 일기 | Day One, 하루콩 | 개인 기록과 감정 |

## 방법

1. 주제 14개를 정하고, 한국어와 영어 키워드로 정규식을 만들어 제목과 본문에서 찾았습니다.
2. 낮은 별점(1~2점, 1,310건)과 높은 별점(4~5점, 3,425건)에서 주제별 언급률을 비교했습니다.
3. 두 비율 차이의 95% 신뢰구간(정규 근사)을 계산해, 0을 포함하면 결론에서 뺐습니다.
4. 주제마다 무작위 표본을 직접 읽어 키워드를 고쳤습니다.

**정확도 점검에서 고친 것**

| 주제 | 문제 | 수정 |
| --- | --- | --- |
| 오류·버그 | "안 돼"가 "기초가 안돼있는데" 같은 평범한 문장까지 잡음 | "안 돼" 제외, 구체적인 오류 표현만 사용 |
| AI·교정 | "고쳐"가 "버그 좀 고쳐 주세요"를 잡음 | "고쳐" 제외 |
| 알림 | "알림장"(학교 알림장)을 잡음 | "알림장" 제외 |
| 재미 | "fun"이 "function"을 잡음 | 단어 경계 추가 |
| 사람 문제 | "차단"이 계정 제재 이야기까지 잡음 | 사람 문제를 가리키는 표현만 남김 |

### 3. 전체 평점과 최근 평점의 차이

앱스토어에 보이는 전체 평점과 최근 리뷰의 평균이 크게 다른 앱이 많았습니다.

| 앱 | 전체 평점 | 최근 리뷰 평균 | 최근 1~2점 비율 |
| --- | ---: | ---: | ---: |
| 헬로톡 | 4.58 | 2.76 | 51.0% |
| 탄뎀 | 4.37 | 2.93 | 45.0% |
| Quizlet | 4.77 | 3.18 | 39.8% |
| 스픽 | 4.80 | 3.25 | 36.4% |
| VoCat | 4.87 | 4.76 | 2.6% |
| 하루콩 | 4.83 | 4.32 | 12.0% |

전체 평점만 보면 놓치는 최근 불만이 있습니다. 리뷰를 쓰는 사람과 별점만 누르는 사람이 다를 수 있어서, 이 차이는 "최근 불만이 늘었다"는 신호로만 봅니다.

## 결정한 것

| 데이터 | 결정 | 구현 |
| --- | --- | --- |
| 복습·암기와 나만의 단어장이 만족 요인 | 내가 모은 표현으로 간격 반복 복습 | 오늘의 복습 (`src/lib/review.js`) |
| 데이터 유실이 일기 앱의 가장 큰 불만 | 데이터 안전을 무료 기본 기능으로 | 삭제 되돌리기, 마지막 백업 날짜 표시, 내려받기 |
| 데이터 유실이 일기 앱의 가장 큰 불만 | **유료화 계획 수정: 자동 백업은 유료로 하지 않음** | 수익화 문서 수정 |
| 재미·꾸준함은 만족 요인, 횟수 제한은 뚜렷한 효과 없음 | 벌칙 없는 꾸준함 | 이번 주 기록과 연속 기록일, 쉬어도 괜찮다는 문구 (`src/lib/activity.js`) |
| 디자인이 일기·단어장 앱의 만족 요인 | 따뜻한 색과 우리 캐릭터 | 말풍선 캐릭터 말랑이, 따뜻한 색감 |
| 가격·구독이 가장 큰 불만 | 기록과 복습은 계속 무료, 자동 갱신 함정 금지 | 유료 기능 시연판에 반영 예정 |
| 대화 앱에서 사람·사기 문제가 자주 언급됨 | 모르는 사람과 연결하는 기능은 넣지 않음 | 공유는 아는 사람에게 보내는 카드로만 검토 |

## 한계

- 한국 App Store 리뷰만 봤습니다. Google Play와 웹 사이트 사용자는 포함하지 않았습니다.
- 앱마다 최근 500건이라 기간이 다릅니다. 듀오링고는 약 2주, 탄뎀은 약 6년입니다. 앱끼리 비교할 때는 이 차이를 감안해야 합니다.
- 키워드 방식이라 반어법과 문맥을 놓칩니다. 표본 확인으로 정확도는 높였지만 재현율은 측정하지 않았습니다.
- 낮은 별점과 주제의 관계는 상관이지 인과가 아닙니다.
- 리뷰를 쓰는 사람은 전체 사용자 중 일부라 의견이 강한 쪽으로 치우칠 수 있습니다.

## 다시 실행하기

```bash
cd analysis
py -3 -m venv .venv
.venv/Scripts/python -m pip install pandas
.venv/Scripts/python collect.py
.venv/Scripts/python analyze.py
.venv/Scripts/python analyze.py --samples
```

`collect.py`는 `data/`에 원본을, `analyze.py`는 `output/`에 집계 표(CSV)와 `summary.json`을 만듭니다. 다시 수집하면 최근 리뷰가 바뀌므로 숫자가 달라집니다.
