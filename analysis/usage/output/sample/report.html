# Daily English 실사용 분석

> **지어낸 예시 데이터로 만든 보고서예요.** 실제 사용자 수치가 아닙니다. 분석 방법을 미리 확인하는 용도예요.

- 대상: 가입한 사람 12명 (관리자 계정 1개, 시연용 계정 0개 제외)
- 기간: 첫 가입 2026-11-25 ~ 마지막 활동 2026-12-15

## 1. 가입하고 실제로 써 봤나

| 지표 | 값 |
| --- | --- |
| 가입 | 12명 (이메일 확인 11명) |
| 기록을 하나라도 남김 | 7 / 12명 (58.3%) |
| 가입 후 하루 안에 첫 기록 | 7명 |
| 첫 기록까지 걸린 시간(중앙값) | 4.6시간 |

## 2. 다시 돌아왔나

| 지표 | 값 |
| --- | --- |
| 다음 날 다시 활동 | 4 / 12명 (33.3%) |
| 7일 안에 다시 활동 | 7 / 12명 (58.3%) |
| 한 사람이 활동한 날(중앙값) | 7일 |

가입 뒤 그 기간이 다 지난 사람만 셌어요.

## 6. 오류와 신고

- 앱 오류 0번, 겪은 사람 0명
- 문제 신고: 콘텐츠 1건

## 이 숫자를 읽을 때

- 사람 수가 적을 때는 비율이 한 사람에 따라 크게 흔들려요. 비율 옆의 사람 수를 같이 보세요.
- 앱은 화면 이동이나 머문 시간을 남기지 않아요. 활동한 날은 기록을 만들거나 고친 날, 문장·반응을 보낸 날, AI 교정을 쓴 날로만 셌어요.
- 복습은 기록마다 마지막 시각만 남아서, 복습만 한 날은 일부 빠질 수 있어요.
- 로그인 없이 쓴 기록은 그 기기에만 있어서 들어 있지 않아요.
- 이메일, 닉네임, 일기·대화·문장 내용은 내보내지 않았어요(export.sql 참고).
