# 실사용 분석

친구 시험이 시작되면, 실제로 가입한 사람들이 앱을 어떻게 쓰는지 숫자로 확인하는 분석이에요.

## 질문

1. 몇 명이 가입했고, 그중 몇 명이 실제로 기록을 남겼나(활성화)?
2. 가입한 사람이 다음 날, 일주일 안에 다시 왔나(재방문)?
3. 어떤 기록을 많이 남기고, 꾸러미와 일기 교정에서 담은 말은 얼마나 되나?
4. 복습에서 얼마나 맞히고, 어떤 꾸러미 말을 많이 헷갈리나?
5. AI 교정과 친구 기능은 얼마나 쓰이나? 오류는 얼마나 나나?

## 순서

1. Supabase 대시보드 > **SQL Editor**에 [`export.sql`](export.sql) 전체를 붙여 넣고 **Run**을 눌러요.
2. 결과 표 오른쪽 위 **Export > CSV**로 내려받아 `analysis/usage/data/export.csv`로 저장해요.
   이 폴더는 `.gitignore`에 있어서 저장소에 올라가지 않아요. 파일을 다른 사람과 공유하지 마세요.
3. 분석을 돌려요.

```powershell
analysis\.venv\Scripts\python -I -X utf8 analysis\usage\analyze.py
```

결과는 `analysis/usage/output/`에 생겨요.

| 파일 | 내용 |
| --- | --- |
| `report.md` | 표로 정리한 보고서(문서와 이력서에 옮기기 좋음) |
| `report.html` | 그래프가 있는 보고서(브라우저로 열기) |
| `summary.json` | 숫자만 |

옵션은 `--since 2026-11-25`(이 날 이후 가입한 사람만)와 `--include-admin`(관리자 계정 포함)이 있어요. 관리자 계정과 학술제 시연용 계정(이메일에 `+demo`, `scripts/make-demo-data.mjs` 참고)은 기본으로 빼요. 시연용 계정은 날짜를 과거로 맞춘 예시 데이터라 실제 수치에 넣으면 안 돼요.

## 실제 데이터 전에 시험하기

`make_sample.py`가 **지어낸** 예시 데이터(친구 12명이 2주 동안 쓴 것처럼)를 만들고, `--sample`로 분석해요.
결과는 `output/sample/`에 생기고, 보고서 맨 위에 예시 데이터라고 적혀요. 이 숫자를 실제 결과로 쓰면 안 돼요.

```powershell
analysis\.venv\Scripts\python -I -X utf8 analysis\usage\make_sample.py
analysis\.venv\Scripts\python -I -X utf8 analysis\usage\analyze.py --sample
```

## 개인정보

앱의 개인정보 처리방침 "이용 통계" 항목과 같은 범위만 내보내요.

- 사람은 가입 순서 번호(`u001`)로만 나와요. 이메일, 닉네임, 사용자 id는 내보내지 않아요.
- 일기, 대화 기록, 친구와 주고받은 문장은 글자 수만 세요.
- 단어·표현·문법은 그 말 자체만 내보내요(뜻, 예문, 메모는 빼요). 보고서에는 **꾸러미에 있는 말만** 글자 그대로 보여 주고, 직접 입력한 말은 개수로만 세요.

## 한계

- 앱은 화면 이동이나 머문 시간을 남기지 않아요. "활동한 날"은 기록을 만들거나 고친 날, 문장·반응을 보낸 날, AI 교정을 쓴 날이에요.
- 복습은 기록마다 마지막 시각만 남아서, 복습만 한 날은 일부 빠질 수 있어요.
- 로그인 없이 쓴 기록은 그 기기에만 있어서 들어 있지 않아요.
- 친구 시험은 사람 수가 적어서, 비율은 한 사람에 따라 크게 흔들려요. 보고서에는 비율과 사람 수를 같이 적어요.
