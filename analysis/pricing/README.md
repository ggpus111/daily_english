# 구독 가격: 얼마를, 어떤 방식으로 받을까

Pro 가격을 처음에는 월 5,900원으로 정했는데 근거가 없었습니다. 그래서 구독형 학습·기록 앱 사용자가 가격의 무엇에 불만을 갖는지, 비슷한 앱은 얼마를 받는지 조사해 **월 4,900원, 한 달 결제만, 무료 체험 뒤 자동 결제 없음**으로 바꿨습니다.

## 질문

1. 구독형 앱 사용자가 가격 때문에 낮은 별점을 줄 때, 문제는 "가격 수준"인가 "결제 방식"인가?
2. 비슷한 앱은 한 달에 얼마를 받나?
3. 그렇다면 Daily English Pro는 얼마를, 어떻게 받아야 하나?

## 방법

1. 가격·구독 리뷰를 세부 주제 8개(비싸다, 자동 결제, 해지, 환불, 무료 기능 축소, 가격 인상, 무료 체험, 값어치)로 나누고, 리뷰 분석과 같은 방식으로 낮은 별점(1~2점)과 높은 별점(4~5점)의 언급률 차이와 95% 신뢰구간을 계산했습니다.
2. 주제마다 표본 15개를 직접 읽어 정확도를 확인했습니다.

| 주제 | 처음 정확도 | 고친 것 | 고친 뒤 |
| --- | ---: | --- | ---: |
| 환불 | 15/15 | | |
| 자동 결제·갱신 | 15/15 | | |
| 해지·구독 취소 | 12/15 | "해지해야 할 듯"(버그 때문에 해지할 생각) 같은 말도 잡혀서, 이름을 "해지가 어렵다"에서 "해지·구독 취소"로 바꿈 | |
| 비싸다 | 8/15 | "부담"이 "길게 써야 한다는 부담"을, "아까워"가 "돈이 안 아까워요"를 잡아서 뺌 | 14/15 |

3. 앱 내 구입 이름에서 기간(1개월, 1년, 월간, 연간)을 읽고, 이름에 기간이 없는 항목(Cake Plus, Quizlet Plus)은 같은 이름 안에서 싼 쪽을 월, 3.5배 이상 비싼 쪽을 연으로 봤습니다. 코인, 수업, 가족·교사용, 첫 구매 할인, 상위 요금제는 개인 기본 구독이 아니라서 뺐습니다. 앱마다 가장 싼 월 요금을 대표 가격으로 썼습니다.

## 결과

### 1. 불만은 가격 수준보다 결제 방식에 있다

| 가격 리뷰 중 | 비율 | 낮은 별점 | 높은 별점 | 차이 95% 신뢰구간 (%p) | 판단 |
| --- | ---: | ---: | ---: | --- | --- |
| 환불 | 29.1% | 38.5% | 21.9% | 10.6 ~ 22.5 | 불만 요인 |
| 해지·구독 취소 | 12.8% | 19.5% | 7.6% | 7.4 ~ 16.4 | 불만 요인 |
| 자동 결제·갱신 | 12.1% | 18.0% | 8.2% | 5.4 ~ 14.3 | 불만 요인 |
| 무료 체험 | 8.2% | 11.3% | 6.4% | 1.2 ~ 8.7 | 불만 요인 |
| 무료 기능이 줄었다 | 6.2% | 6.7% | 6.4% | -2.9 ~ 3.6 | 차이 없음 |
| 비싸다·가격 부담 | 4.4% | 4.1% | 5.3% | -4.0 ~ 1.5 | 차이 없음 |
| 가격 인상 | 0.5% | | | | 너무 적음 |

- "비싸다"는 가격 리뷰의 4.4%뿐이고, 낮은 별점과 높은 별점에서 비슷하게 나왔습니다. 높은 별점 리뷰에서도 "좀 비싸지만 좋다"는 말이 나옵니다.
- 반대로 환불, 해지, 자동 결제, 무료 체험은 모두 낮은 별점에서 뚜렷하게 많았습니다. 표본을 읽어 보면 대부분 "7일 무료 체험을 눌렀는데 1년치가 결제됐다", "해지했는데 또 결제됐다"였습니다.
- 최근 1년만 보면 해지 이야기가 12.8% → 18.8%로 늘었습니다.
- 리뷰에 적힌 금액(128개)의 중앙값은 **60,000원**이었습니다. 한 달 요금이 아니라 체험 뒤 한꺼번에 빠져나간 연간 결제 금액이 대부분입니다.
- 서울시 조사도 같은 방향입니다. 무료 체험 뒤 유료 전환이나 자동 결제를 겪은 사람이 56%, 그중 49%가 안내가 부족했다고 답했고, 58.4%가 해지에 어려움을 겪었습니다(해지 메뉴를 찾기 어려움 52.4%).

### 2. 비슷한 앱의 한 달 가격 (2026-11-15, 한국 App Store)

| 묶음 | 앱 | 월 | 연 | 연을 12로 나눈 값 |
| --- | --- | ---: | ---: | ---: |
| 기록·단어장 | 하루콩 | 2,500원 | 12,000원 | 1,000원 |
| 기록·단어장 | VoCat | 4,900원 | 40,900원 | 3,410원 |
| 기록·단어장 | Quizlet | 9,900원 | 44,000원 | 3,670원 |
| 기록·단어장 | Day One | 12,000원 | 66,000원 | 5,500원 |
| 학습 | 케이크 | 16,000원 | 85,000원 | 7,080원 |
| 학습 | 말해보카 | 19,500원 | 119,000원 | 9,920원 |
| 학습 | 스픽 | 29,000원 | 129,000원 | 10,750원 |
| 학습 | 듀오링고 | (목록에 없음) | 100,000원 | 8,330원 |
| 대화 | 헬로톡 | 16,900원 | 105,000원 | 8,750원 |
| 대화 | 탄뎀 | 21,500원 | 89,000원 | 7,420원 |

- 기록·단어장 앱 4개의 월 가격 중앙값은 **7,400원**(2,500~12,000원), 콘텐츠와 AI 수업을 파는 학습·대화 앱은 16,000~29,000원입니다.
- 10개 앱 모두 연간 요금을 두고, 연간 요금은 월 요금 12번보다 30~66% 쌉니다. 앱들이 연간 결제를 밀어주는 구조이고, 그 연간 결제가 체험 뒤 한꺼번에 빠져나가며 환불 불만이 됩니다.
- 참고: 전 세계 교육 앱의 월 가격 중앙값은 $9.99(RevenueCat 2026)입니다. 미국 중심 수치라 한국 가격과 직접 비교하지는 않았습니다.

## 결정

| 근거 | 결정 |
| --- | --- |
| Daily English는 콘텐츠를 파는 학습 앱이 아니라 기록·단어장 앱이고, Pro에는 학습 통계와 앱 안 AI 교정 두 가지뿐 | 가장 비슷한 단어장 앱 VoCat의 기본 요금과 같은 **월 4,900원**. 기록·단어장 앱 중앙값(7,400원)보다 낮고, 5,000원 아래 가격대 |
| 앱 안 AI 교정은 쓸 때마다 비용이 듦 | 3,900원도 검토했지만, AI 비용을 감당할 여유를 두려고 4,900원을 고름 |
| "비싸다"는 별점과 관계가 뚜렷하지 않음 | 가격을 더 낮추기보다(무료에 가깝게) 결제 방식을 바꾸는 데 집중 |
| 환불·자동 결제 불만의 대부분이 체험 뒤 한꺼번에 빠져나간 연간 결제 | **연간 요금제를 두지 않고 한 달 결제만** |
| 무료 체험 뒤 자동 전환이 불만 요인 | **무료 체험이 끝나도 저절로 결제하지 않음**. 계속 쓰고 싶을 때 직접 결제 |
| 해지가 어렵다는 불만이 늘고 있음 | 해지는 앱 안에서 바로, 남은 기간까지 사용 |
| 리뷰 분석에서 기록 유실이 큰 불만 | 기록·복습·백업은 계속 무료 |

가격은 `src/lib/i18n.js`의 `planProPrice`, 약속 문구는 `proPromise.*`에 있습니다. 시연판이라 실제 결제는 없습니다.

**받는 돈 계산(참고)**: 앱 마켓의 소규모 개발자 수수료 15%와 부가세 10%를 빼면 한 명당 한 달 약 3,800원입니다(4,900 ÷ 1.1 × 0.85). 3,900원이면 약 3,000원이라, 4,900원이 AI 비용을 감당할 여유가 25% 더 큽니다. 앱 안 AI 교정은 호출할 때마다 비용이 들기 때문에, 출시 전에 AI 사용 요금을 계산해 하루 사용 횟수 상한을 정해야 합니다.

## 한계

- **실제 지불 의향을 묻지 않았습니다.** 리뷰와 다른 앱 가격으로 추정한 가격이라, 출시 전에 "얼마면 쓰겠는가" 설문(Van Westendorp 같은 방법)으로 확인해야 합니다.
- **앱 내 구입 목록은 많이 팔린 10개만 보입니다.** 지역·기간 할인 가격이 섞여 있을 수 있어, 앱마다 가장 싼 월 요금을 대표값으로 썼습니다.
- **자동 전환이 없는 무료 체험은 유료 전환율을 낮출 수 있습니다.** 이번 결정은 매출보다 신뢰를 먼저 고른 것입니다.
- 리뷰는 한국 App Store만, 서울시 조사는 서울시민만 대상입니다.
